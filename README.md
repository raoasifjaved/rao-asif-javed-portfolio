# Rao Asif Javed — Portfolio Website

A responsive, animated, static portfolio website built with plain HTML, CSS and JavaScript. No framework, package manager, database or paid hosting dependency is required.

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. The CV download is available at `assets/Rao_Asif_Javed_CV_Public.pdf`.

The Google Fonts import is optional; local system font fallbacks are included in the CSS.

## Publish with free GitHub Pages hosting

Your GitHub username, linked from your CV, is `raoasifjaved`.

1. Sign in to [GitHub](https://github.com/raoasifjaved).
2. Create a **public** repository named exactly `raoasifjaved.github.io`.
3. Upload the contents of this portfolio folder to the **root** of that repository. `index.html` must be at the root, not inside another nested folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and the `/ (root)` folder, then save.
6. After GitHub Pages publishes it, visit `https://raoasifjaved.github.io`.

GitHub Pages supports static HTML, CSS and JavaScript hosting from public repositories on GitHub Free. The site URL above is the expected user-site address; it becomes live only after you create the repository and enable Pages. See the official [GitHub Pages overview](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) and [quickstart](https://docs.github.com/en/pages/quickstart).
